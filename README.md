# אולפני סברס · Sabres Studios

אתר אולפני סברס: חדר חזרות ואולפן מטופל אקוסטית ברחוב הנגר 24, הוד השרון (בניין B, קומה P1). האתר רץ ב־sabres.studio.

| קובץ | מה זה |
|---|---|
| `public/index.html` | האתר עצמו בעמוד אחד: פתיחה, החדר, תמונות, על המקום, מחיר, קביעת חזרה, איך מגיעים ויצירת קשר |
| `worker.js` | השרת (Cloudflare Worker): מגיש את האתר ושולח בקשות חזרה במייל |
| `wrangler.jsonc` | הגדרות הפרסום, הנמענים וכתובת השולח |

## קביעת חזרה במייל אוטומטי
המבקש בוחר יום, אורך ושעה, ממלא פרטים ולוחץ שליחה. השרת שולח מייל מסודר דרך Resend ל־beno842003@gmail.com עם העתק ל־amitzil03@gmail.com, והמבקש רואה ״הבקשה נשלחה לאולפן״. אם השליחה נכשלת, הטופס מציע לפתוח מייל מוכן במקום.

הפעלה, פעם אחת:
1. פותחים חשבון ב־[Resend](https://resend.com), מוסיפים את הדומיין `sabres.studio`, ומוסיפים ב־Cloudflare DNS את הרשומות ש־Resend נותן.
2. יוצרים API key ב־Resend ושומרים אותו כסוד:
   ```
   npx wrangler@4 secret put RESEND_API_KEY
   ```
3. מפרסמים:
   ```
   npx wrangler@4 deploy
   ```
